## 🌟 Возможности и структура сайта

1. **`index.html` (Главная):**
   - Первый экран с фирменным баннером, бейджем «Гарантия 10 лет», ключевыми УТП.
   - Популярные решения (теневые EuroKRAAB, световые линии, магнитные треки).
   - Интерактивный ползунок «До / После» монтажа.
   - Экспресс-калькулятор сметы в реальном времени.
   - Преимущества, схема работы и форма записи на замер.

2. **`catalog.html` (Каталог):**
   - Теневые потолки EuroKRAAB 2.0.
   - Световые линии Light Lines.
   - Парящие потолки с контурной LED-подсветкой.
   - Встраиваемые магнитные трековые системы 48V.
   - Классические матовые, сатиновые и глянцевые полотна MSD Premium.
   - Скрытые ниши под карниз для штор ПК-5 и Lumfer.

3. **`calculator.html` (Калькулятор стоимости):**
   - Выбор типа помещения и интерактивный ползунок площади (от 5 до 120 м²).
   - Выбор фактур, профилей, количества светильников, люстр, световых линий и треков.
   - Автоматический учет объема и скидки (до 15%).
   - Экспорт готовой сметы в один клик в WhatsApp мастеру Петру.

4. **`portfolio.html` (Наши работы):**
   - Фильтрация по категориям (Теневые, Световые линии, Гостиные, Спальни, Кухни, Санузлы).
   - Подробные карточки с фотографиями, сроками и реальными ценами.
   - Ссылка на свежие работы в группе ВК.

5. **`prices.html` (Цены и акции):**
   - Тарифные планы («Комфорт», «Теневой Стиль», «Премиум Hi-Tech»).
   - Детальный прайс-лист на все виды полотен, профилей и доп. работ.
   - Действующие акции (светильники в подарок, скидка новоселам 10%, бесплатный замер).

6. **`contacts.html` (Контакты):**
   - Прямые телефоны мастера Петра, режим работы с 08:00 до 22:00.
   - Ссылки на ВКонтакте, WhatsApp.
   - Форма вызова замерщика на удобное время.
   - Подробный FAQ (ответы на частые вопросы клиентов).

## 🚀 Как опубликовать на GitHub Pages за 2 минуты:

1. **Создайте новый репозиторий на GitHub** (например, `newline-potolki` или `new-line`).
2. **Загрузите все файлы из этой папки** в репозиторий (включая файл `.nojekyll`, все `.html` файлы и папку `assets`).
3. В репозитории на GitHub перейдите в **Settings** (Настройки) → **Pages** (слева в меню).
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: **main** (или `master`) / folder: **/(root)**
5. Нажмите **Save**. Через 30-60 секунд ваш сайт будет доступен по адресу:
   `https://ВАШ_ЛОГИН.github.io/newline-potolki/`

> Все пути к файлам и стилям прописаны относительно (`./`), поэтому сайт гарантированно работает на GitHub Pages в любом подкаталоге!
